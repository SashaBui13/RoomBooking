Room Booking System
Вебзастосунок для автоматизації оренди конференц-залів та управління супутніми послугами. 
Реалізований на платформі ASP.NET Core MVC з дотриманням принципів Clean Architecture.

Архітектура системи

Проєкт розділено на 4 ізольовані шари:
Domain — доменні сутності (Room, Booking, RoomService), 
правила валідації та інтерфейси ціноутворення.

Application — сценарії використання (Use Cases), 
бізнес-сервіси, контракти репозиторіїв/контексту, DTO та моделі представлення.

Infrastructure — налаштування Entity Framework Core, робота з базою даних SQL Server (LocalDB) та міграції.

Presentation (Web) — MVC-контролери, стилізовані Razor-представлення для клієнтської взаємодії.

Бізнес-логіка
Динамічне ціноутворення:Ранок (06:00 – 09:00): знижка 10% ($k = 0.90$).
Стандартний час (09:00 – 12:00, 14:00 – 18:00): базова ставка ($k = 1.0$).
Піковий час (12:00 – 14:00): націнка 15% ($k = 1.15$).
Вечір (18:00 – 23:00): знижка 20% ($k = 0.80$).
Погодинний розрахунок враховує змішані інтервали при переході між зонами.

Додаткові послуги: можливість вибору послуг для кожного залу із включенням їхньої фіксованої вартості 
до фінального чека.

Валідація:Перевірка місткості залу (заборона бронювання при перевищенні ліміту учасників).
Запобігання конфліктам у розкладі (неможливість повторного бронювання на перекриті інтервали; дозволено стик-у-стик).

Тестування
Проєкт RoomBooking.UnitTests покриває ключові вимоги за допомогою фреймворку xUnit:
Розрахунок погодинних тарифів для всіх часових зон.
Розрахунок вартості для змішаних часових інтервалів.
Коректність включення додаткових послуг у загальну суму.
Генерація винятків при невалідних часових проміжках.
Блокування створення бронювання при переповненні залу.
Заборона бронювання при перетині часу з існуючими записами.Дозвіл бронювання стик-у-стик.
